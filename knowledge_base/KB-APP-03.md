# KB-APP-03 — Application qui ne démarre plus

Catégorie : Logiciels et applications
Priorité habituelle : basse à moyenne

## Symptômes
Une application métier ou bureautique ne se lance plus, se ferme immédiatement, ou affiche une erreur au démarrage.

## Diagnostic
1. Identifier l'application concernée et sa version via consulter_equipement.
2. Vérifier si l'erreur est déjà connue en consultant les incidents actifs liés à cette application.
3. Demander à l'utilisateur si une mise à jour a été effectuée récemment.

## Procédure de résolution
1. Redémarrer l'application, puis le poste si le problème persiste.
2. Vérifier l'espace disque disponible (une application peut échouer au démarrage si le disque est presque plein).
3. Réinstaller l'application si le problème persiste après redémarrage.
4. Si l'application est critique pour l'activité de l'utilisateur et qu'aucune solution rapide n'est trouvée, escalader vers l'équipe applicative avec priorité augmentée.
