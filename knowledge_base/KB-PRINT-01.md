# KB-PRINT-01 — Impression impossible

Catégorie : Imprimantes et périphériques
Priorité habituelle : basse

## Symptômes
Le document envoyé à l'imprimante reste bloqué dans la file d'attente, ou l'imprimante n'apparaît plus comme disponible.

## Procédure de résolution
1. Vérifier via verifier_etat_service que le service d'impression réseau est actif.
2. Vider la file d'attente d'impression du poste utilisateur.
3. Vérifier que l'imprimante est allumée, connectée au réseau, et qu'elle n'affiche pas d'erreur (bourrage, manque de papier ou d'encre).
4. Redémarrer le spouleur d'impression si le problème persiste.
5. Si plusieurs utilisateurs sont concernés par la même imprimante, créer un ticket matériel pour intervention.
