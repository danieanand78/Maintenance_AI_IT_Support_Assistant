# KB-AUTH-02 — Compte utilisateur verrouillé

Catégorie : Comptes et authentification
Priorité habituelle : moyenne

## Symptômes
Le compte se verrouille après plusieurs tentatives de connexion échouées. L'utilisateur reçoit un message indiquant que le compte est bloqué.

## Procédure de résolution
1. Confirmer le verrouillage via consulter_equipement ou l'outil de gestion des comptes.
2. Vérifier qu'il ne s'agit pas d'une tentative d'intrusion (plusieurs échecs depuis une localisation inhabituelle).
3. Si aucune activité suspecte n'est détectée, déverrouiller le compte après confirmation de l'identité de l'utilisateur.
4. Si une activité suspecte est détectée, escalader vers l'équipe cybersécurité avant tout déverrouillage.

## Points de sécurité
Un déverrouillage suite à une activité suspecte doit systématiquement être escaladé et validé par un humain.
